# Project-owned skills

`skills.json` is a small discovery index, not a package manager or mirror. The
two agentG foundation skills live in this repository's `skills/`. Application
skills remain authoritative in the repositories that own the software.

For dndsR, read the
[reviewed skill](https://github.com/Scrumpis/dndsR/blob/3f86d428be627439902642e0ac9e106a96d6b840/skills/dndsr/SKILL.md),
then its verification and limitations records at the same revision. Review
commands against the software version you actually intend to run. The catalog
does not install it, authorize its commands, or transfer its validation claims
to agentG.

To add or refresh an entry, inspect source ownership, scope, license, immutable
revision and test evidence. Update the JSON and explain material changes in a
local review. A branch name is a discovery hint, never a reproducible pin.
Do not fetch or update skills silently during an analysis. Catalog entries may
be stale; their date records an inspection, not a support guarantee.
