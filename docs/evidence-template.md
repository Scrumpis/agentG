Use “not tested” where appropriate. A table is optional; an artifact link plus
an explanation can be enough. Do not include credentials, private paths or
unpublished results in public evidence. This template is an agentG record, not
a CODECHECK certificate, rOpenSci approval or a PROV/RO-Crate serialization.
